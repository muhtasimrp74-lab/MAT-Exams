## নতুন অধ্যায় যোগ করার নিয়ম
1. প্রশ্নগুলো MD ফরম্যাটে লেখো (`**প্রশ্ন ১.** ...`, `(ক)..(ঘ)`, `✅ **উত্তর: (খ)** — ব্যাখ্যা`, সেকশনের জন্য `## সেকশন ১: টপিক`)।
2. চালাও: `python3 tools/md_to_chapter.py file.md --id bio2-04-xyz --subject জীববিজ্ঞান --paper "২য় পত্র · অধ্যায় ৪" --title "অধ্যায়ের নাম"`
3. `git add . && git commit -m "add chapter" && git push` — ১-২ মিনিটে লিংকে নতুন অধ্যায় দেখা যাবে।

পুরনো অধ্যায় সংশোধন করলে `data/manifest.js`-এ ওই অধ্যায়ের `"v"` সংখ্যা বাড়িয়ে দাও (ক্যাশ ভাঙতে)।
